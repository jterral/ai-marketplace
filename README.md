# AI Marketplace

A Claude Code plugin marketplace of reusable skills, rules, commands, and agents: git workflow, code auditing, API testing, and .NET and Flutter conventions.

## 📋 Overview

This repository is a [Claude Code plugin marketplace](https://docs.claude.com/en/docs/claude-code/plugins). Each plugin lives under `plugins/{name}/` and can be installed independently. Skills can also be pulled individually with [APM (Agent Package Manager)](https://github.com/microsoft/apm).

## 🔌 Plugins

The catalog below is generated from `.claude-plugin/marketplace.json` and the plugin directories. Run `node scripts/generate-docs.mjs` after adding or changing a plugin, skill, command or agent.

### code-auditor

Autonomous code audit plugin: /audit command, auditor agent, clean-architecture / security-leak / critical-quality skills

```txt
/plugin install code-auditor@ai-marketplace
```

| Component | Type | Description |
| --------- | ---- | ----------- |
| `/audit` | command | Run a code audit (scope: "pr" for current branch diff, "full" for the whole codebase) |
| `auditor` | agent | Audits code for quality, architecture, and security issues |
| [audit-architecture](./plugins/code-auditor/skills/audit-architecture/SKILL.md) | skill | Technology-agnostic Clean Architecture audit checking layer boundaries, dependency direction, domain isolation, and coupling |
| [audit-quality](./plugins/code-auditor/skills/audit-quality/SKILL.md) | skill | Very demanding code quality audit covering readability, error handling, tests, performance, observability, and technical debt |
| [audit-security](./plugins/code-auditor/skills/audit-security/SKILL.md) | skill | Security audit detecting secret leaks (API keys, tokens, passwords, connection strings), sensitive data in logs, injection risks, missing input validation, and authn/authz gaps |

## 📦 Use with APM

Plugins can be pulled into any project's `apm.yml`:

```yaml
dependencies:
  apm:
    - jterral/ai-marketplace/plugins/git-workflow
    - jterral/ai-marketplace/plugins/dotnet
```

Then run `apm update` to install them.

## 🏷️ Releases

Every merge to `main` is tagged by [GitVersion](https://gitversion.net/) from the Conventional Commits history. The changelog is the generated notes of each [GitHub release](https://github.com/jterral/ai-marketplace/releases).

## 🤝 Contributing

See [CLAUDE.md](CLAUDE.md) for the skill format, conventions and validation checklist. In short:

1. Follow [Conventional Commits](plugins/git-workflow/skills/git-conventional-commit/SKILL.md) for all commits and PR titles
2. Run `node scripts/validate-marketplace.mjs` and `node scripts/generate-docs.mjs` before opening a PR (CI runs both)
3. Update documentation as needed
